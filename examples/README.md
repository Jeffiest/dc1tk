# Example mods

Mods that ship with the project, to show what a mod can do. Build one over
a decompiled tree (`c2 setup dc2.iso` writes it) with `--mods examples`:

```
c2 mod test extracted/scripts calculator --mods examples
c2 build extracted/scripts dc2.iso -o calculator.iso --mod calculator --mods examples
```

## calculator

A desk calculator stands in Barga's Valley, where a new game with the mod
starts. Walk up to it and press the action button at the "!" to open it:
a calculator face with a cursor on its keys (D-pad to move, (X) to press,
(O) or the power key to close; [start] clears, (#) erases, the shoulder
buttons are + - x /, (^) is =), an LCD of its own digits, and a sound for
each key.

What it shows:

- a patch (`calculator.c`, `#pragma target map s17`) that overrides the
  function the map's "talk" point runs and adds a start program numbered by
  build (`NEW_PROGRAM`), which `start_at` in `mod.json` names;
- new files from common formats: the model (`model/calc.gltf`, made like
  the game's fishing float) and the face, cursor and digits (`ui/*.png`,
  made like the title logo), loaded with `load_chara` and `load_image`;
- new sound effects (`sounds/*.wav`) added to a bank nothing else loads,
  whose names the patch plays by;
- logic kept apart from drawing (`logic.c`), tested without the game by
  `tests.c` (`c2 mod test`).

Its art, model and sounds are generated by
`cargo run --release -p c2-assets --example calculator_art -- examples/calculator`.

`numbers.json` keeps the numbers build gave the examples' `NEW_` names.
