Walkthroughs of the changes you'll most often be asked for. Each one builds on the tour of the
game's scripts in the [coding overview](../README.md); code in them is new code written for these
pages.

- [Change what an NPC says](npc-line.md): find the talk handler, edit every language.
- [Make an enemy behave differently](enemy-behaviour.md): edit its AI, without touching 35 other
  monsters.
- [Add a new enemy to a fight](new-enemy.md): what's possible, and the recipe.
- [Add a cutscene to a town](cutscene.md): a complete mod, from free numbers to testing.
- [Tune the player](tune-player.md): make Max's combo more forgiving.
- [A caption every five seconds during a fight](captions.md).
