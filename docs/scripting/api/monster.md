# Monster AI scripts: `<monster.h>`

Natives for monster AI scripts (dungeon/monster). They act on the monster running the script.

Natives are engine functions, declared extern with their number in NATIVE(...). A native with one result returns it (count = get_counter(3);); natives with several results take pointers (get_actor_pos(0, &x, &y, &z);). Natives push nothing on the VM stack: a native in an expression is called first, into a hidden local, and the expression reads that. OPTIONAL(...) lists arguments a call may leave out. Natives never wait; scripts wait with `wait;`, which yields one frame (25 a second on PAL). While the player skips a cutscene the engine does not run natives until the script reaches `skip_end;`.

NATIVE(B, N) means the game's scripts call the native as B + N. A call can pick another form with an AT(B) or DIRECT prefix.

The declarations are in `sdk/monster.h` and `sdk/helpers/monster.h`; [the SDK](../sdk.md) explains how they are written, and [the API](README.md) lists the other headers. Generated by `dc2tk api-docs` from the SDK's headers; change the headers, not this page.

## Programs

The program numbers the engine starts (`enum program`): a script lists the ones it answers with `PROGRAM(name, function);`.

| Program | Number | When it runs |
| --- | --- | --- |
| `init` | 100 | Runs once when the monster is placed, right after its script is loaded (monster.cpp sets req_prog MONSTER_PROG_INIT and runs it before switching to 200). |
| `update` | 200 | Normal behaviour loop: resumed every frame and restarted whenever the running program ends (runscript_opcodes.cpp CMonsterMan::RunScript, MONSTER_PROG_MAIN). |
| `stopped` | 400 | Runs when a hit lands on a monster under the stop status or inflicts it (monster.cpp reaction 3, status bits 0x8/0x20, MONSTER_PROG_STATUS); retail bodies hold the damage pose until the status clears. |
| `damage` | 500 | Runs when a hit staggers the monster (monster.cpp reaction 2 once the stagger total reaches the table limit, MONSTER_PROG_DAMAGE). |
| `knockdown` | 600 | Runs when a hit with the knockdown flag knocks the monster over (monster.cpp reaction 4, MONSTER_PROG_KNOCK). |
| `guard` | 700 | Runs when the monster guards a hit or takes no damage from it (monster.cpp MONSTER_PROG_GUARD). |
| `dodge_melee` | 800 | Runs when the monster rolls its escape_rate0 chance to dodge an attack that its target started with murderous mode 0, which the action scripts set for melee swings (monster.cpp MONSTER_PROG_ESCAPE_0). |
| `dodge_shot` | 900 | Runs when the monster rolls its escape_rate1 chance to dodge an attack that its target started with murderous mode 1, which the action scripts set when firing a gun (monster.cpp MONSTER_PROG_ESCAPE_1). |
| `death` | 1000 | Runs when a hit brings the monster's life to zero or a death request arrives (monster.cpp reaction 6 and damage_req 4, MONSTER_PROG_DEAD). |
| `lifted` | 1100 | Runs when the player picks the monster up and carries it (monster.cpp sets catch_state 1 and req_prog 1100). |
| `land` | 1200 | Runs when a thrown monster hits the ground (monster.cpp catch_state 2 on landing, MONSTER_PROG_LAND). |
| `stun` | 1400 | Runs when the monster is stunned by a stun hit, a nearby shock or a thrown monster colliding with it (monster.cpp MONSTER_PROG_PIYORI, sets piyori_time). |
