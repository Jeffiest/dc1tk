# Argument files: `<arg.h>`

Natives for event argument files loaded with load_arg.

Natives are engine functions, declared extern with their number in NATIVE(...). A native with one result returns it (count = get_counter(3);); natives with several results take pointers (get_actor_pos(0, &x, &y, &z);). Natives push nothing on the VM stack: a native in an expression is called first, into a hidden local, and the expression reads that. OPTIONAL(...) lists arguments a call may leave out. Natives never wait; scripts wait with `wait;`, which yields one frame (25 a second on PAL). While the player skips a cutscene the engine does not run natives until the script reaches `skip_end;`.

NATIVE(B, N) means the game's scripts call the native as B + N. A call can pick another form with an AT(B) or DIRECT prefix.

The declarations are in `sdk/arg.h` and `sdk/helpers/arg.h`; [the SDK](../sdk.md) explains how they are written, and [the API](README.md) lists the other headers. Generated by `dc2tk api-docs` from the SDK's headers; change the headers, not this page.

### add_arg_record

```c
extern void add_arg_record(any value, ...) NATIVE(0);
```

Stores all its arguments (ints, floats and strings, in order) as one argument record under the next record id, then adds 1 to that id. Event natives called with a single record id read their arguments from the matching record.

Original name: `_DATA`.

### set_arg_record_id

```c
extern void set_arg_record_id(int next_id) NATIVE(1);
```

Sets the id that the next add_arg_record call stores its record under; ids start at 0.

Original name: `_ID_OFFSET`.

## Helpers

A helper stands for the native calls in its body: the compiler expands it in place, and the decompiler folds every run it matches.

| Helper | What it does |
| --- | --- |
| [`add_actor_place_records`](#add_actor_place_records) | Adds the two records that place an actor: its position (actor, x, y, z), then its yaw as (actor, 0.0, yaw, 0.0). |

### add_actor_place_records

Adds the two records that place an actor: its position (actor, x, y, z), then its yaw as (actor, 0.0, yaw, 0.0).

```c
static inline void add_actor_place_records(int actor, float x, float y, float z, float yaw)
{
    add_arg_record(actor, x, y, z);
    add_arg_record(actor, 0.0, yaw, 0.0);
}
```
