# The API

Every native, helper, program, constant and value kind the SDK declares, a page a header, and the functions of the modkit libraries. A script includes the header of its kind of script, which declares the natives the engine gives that kind; [the SDK](../language.md) explains how the headers are written, and [the overview](../README.md) what each kind of script does. Generated by `dc2tk api-docs` from the SDK's headers; change the headers, not this page.
