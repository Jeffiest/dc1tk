# Action scripts: `<action.h>`

Natives for character action scripts (mainchr, dungeon/act_script). They act on the character running the script.

Natives are engine functions, declared extern with their number in NATIVE(...). A native with one result returns it (count = get_counter(3);); natives with several results take pointers (get_actor_pos(0, &x, &y, &z);). Natives push nothing on the VM stack: a native in an expression is called first, into a hidden local, and the expression reads that. OPTIONAL(...) lists arguments a call may leave out. Natives never wait; scripts wait with `wait;`, which yields one frame (25 a second on PAL). While the player skips a cutscene the engine does not run natives until the script reaches `skip_end;`.

NATIVE(B, N) means the game's scripts call the native as B + N. A call can pick another form with an AT(B) or DIRECT prefix.

The declarations are in `sdk/action.h` and `sdk/helpers/action.h`; [the SDK](../sdk.md) explains how they are written, and [the API](README.md) lists the other headers. Generated by `dc2tk api-docs` from the SDK's headers; change the headers, not this page.

## Helpers

A helper stands for the native calls in its body: the compiler expands it in place, and the decompiler folds every run it matches.

| Helper | What it does |
| --- | --- |
| [`advance_combo`](#advance_combo) | Stores the next combo step, clears the attack press history and sets menace level 0 for 3 frames, as each hit of a combo does when it starts. |
| [`start_combo_hit`](#start_combo_hit) | Starts the next hit of a sword combo: plays its motion once from the first frame, turns toward a target within reach, stores the combo step, clears the attack press history and sets menace. |
| [`play_motion_once`](#play_motion_once) | Plays a motion once at its own speed, from its first frame without blending, stopping on its last frame (flags 4 \| 2). |
| [`add_blade_trail`](#add_blade_trail) | Schedules a sword trail in slot 0 between the blade frames "dcol00" and "dcol01" with length 77, while the motion plays between start_ratio and end_ratio. |

### advance_combo

Stores the next combo step, clears the attack press history and sets menace level 0 for 3 frames, as each hit of a combo does when it starts.

```c
static inline void advance_combo(int step)
{
    set_saved_value(step);
    reset_attack_presses();
    set_menace(MENACE_MELEE, 3);
}
```

### start_combo_hit

Starts the next hit of a sword combo: plays its motion once from the first frame, turns toward a target within reach, stores the combo step, clears the attack press history and sets menace.

```c
static inline void start_combo_hit(string motion, int step)
{
    play_motion(motion, -1, CHARA_MOTION_RESTART | CHARA_MOTION_HOLD);
    turn_to_target(2.0 * 20.0, 2.0);
    set_saved_value(step);
    reset_attack_presses();
    set_menace(MENACE_MELEE, 3);
}
```

### play_motion_once

Plays a motion once at its own speed, from its first frame without blending, stopping on its last frame (flags 4 | 2).

```c
static inline void play_motion_once(string motion)
{
    play_motion(motion, -1, CHARA_MOTION_RESTART | CHARA_MOTION_HOLD);
}
```

### add_blade_trail

Schedules a sword trail in slot 0 between the blade frames "dcol00" and "dcol01" with length 77, while the motion plays between start_ratio and end_ratio.

```c
static inline void add_blade_trail(string motion_name, float start_ratio, float end_ratio, int hold_frames, int fade_frames)
{
    add_sword_trail(0, motion_name, start_ratio, end_ratio, "dcol00", "dcol01", 77, hold_frames, fade_frames);
}
```

## Programs

The program numbers the engine starts (`enum program`): a script lists the ones it answers with `PROGRAM(name, function);`.

| Program | Number | When it runs |
| --- | --- | --- |
| `init` | 100 | Runs once when the character's action script is set up (actionchara.cpp CActionChara::InitScript, ACTION_PROG_INIT), before 200 takes over. |
| `reset` | 150 | Runs when the character is put back into its normal state (actionchara.cpp CActionChara::ResetAction, ACTION_PROG_RESET, also reached from the event native that resets a character), before 200 takes over. |
| `update` | 200 | Normal control loop: resumed every frame and restarted whenever the running program ends (actionchara.cpp CActionChara::RunScript, ACTION_PROG_MAIN). |
| `damage` | 500 | Runs when a hit asks for a small damage reaction (actionchara.cpp ACTION_DAMAGE_REQ_SMALL, ACTION_PROG_DAMAGE_SMALL). |
| `stopped` | 550 | Runs when the character is frozen by the stop status, from a hit with that reaction or from the menu while the status is set (actionchara.cpp SetHold and ACTION_DAMAGE_REQ_HOLD, status bits 0x8/0x20); retail bodies hold the damage pose until it clears. |
| `knockdown` | 600 | Runs when a hit asks for a large damage reaction (actionchara.cpp ACTION_DAMAGE_REQ_LARGE, ACTION_PROG_DAMAGE_LARGE); retail bodies blow the character away and get up. |
| `blocked` | 700 | Runs after the character's melee hit is guarded by a monster or deals no damage (monster.cpp sets melee_hit, actionchara.cpp switches to 700); retail bodies play the after-guard recoil motion. |
| `death` | 1400 | Runs when the character's HP reaches zero (actionchara.cpp ACTION_DAMAGE_REQ_DEAD, ACTION_PROG_DEAD), which also queues dungeon event 1200. |
| `land` | 1500 | Runs when Max or Monica lands hard after falling at 3.5 units per frame or faster (actionchara.cpp ACTION_PROG_LAND). |
