# modkit

`sdk/modkit/` holds libraries for mods, written for this project rather than taken from the game. A script includes one with a quoted include (`#include "modkit/text.c"`), which is looked for in the script's folders and then in `sdk/`. Generated by `dc2tk api-docs` from the SDK's headers; change the headers, not this page.

## modkit/input.c

modkit input: buttons and waiting, for event (map) scripts. Include with #include "modkit/input.c". Button masks are the PAD\_ constants of \<event.h\>; frames are 50 a second on a PAL console.

### modkit_wait

Waits the given number of frames.

```c
void modkit_wait(int frames)
{
    while (frames-- > 0) {
        wait;
    }
}
```

### modkit_pressed

Returns the buttons of mask pressed this frame, 0 when none.

```c
int modkit_pressed(int mask)
{
    return get_pad_pressed() & mask;
}
```

### modkit_wait_for_button

Waits until a button of mask is pressed and returns the buttons pressed. A button already held down when this starts has to be pressed again.

```c
int modkit_wait_for_button(int mask)
{
    int pressed;

    wait;
    while (!(pressed = get_pad_pressed() & mask)) {
        wait;
    }
    return pressed;
}
```

### modkit_wait_for_confirm

Waits for (X) or (O).

```c
void modkit_wait_for_confirm(void)
{
    modkit_wait_for_button(PAD_CROSS | PAD_CIRCLE);
}
```

## modkit/text.c

modkit text: message windows for event (map) scripts. Include with #include "modkit/text.c".

Text is shown at once, without the game's button prompt, in the top slot the game uses for its hints. It can hold the codes the game's own text uses: \[Number1] to \[Number16] for numbers set with set_message_value before the text is shown (showing it lays the numbers out, so a value set after shows 0), button icons such as (X), (O), \[r1] and \[select], \\n for a new line, and \<page\> for a page break (see docs/game/running.md, "Message text"). Window 0 is the event window, which stays on screen after an event ends until closed (see docs/game/running.md).

### modkit_text_open

Gets window ready for text the script controls.

```c
void modkit_text_open(int window)
{
    apply_message_preset(window, MES_PRESET_WINDOW);
    set_message_window_mode(window, MES_WIN_VERSATILE_1);
    set_message_speed(window, 0);
    set_message_prompt(window, 0);
}
```

### modkit_text_show

Shows text in window, replacing what it showed.

```c
void modkit_text_show(int window, string text)
{
    show_message(window, text);
    show_message(window, -1);
    set_message_slot(window, 8);
    place_message_bubble(window, 0, 0, 0, 0);
}
```

### modkit_text_close

Closes window and gives back the game's default button prompt.

```c
void modkit_text_close(int window)
{
    set_message_prompt(window, 1);
    set_message_cursor(window, -1);
    close_message(window);
    set_message_slot(window, 0);
}
```

### modkit_say

Shows text in window 0 until the player presses (X) or (O), then closes it.

```c
void modkit_say(string text)
{
    modkit_text_open(0);
    modkit_text_show(0, text);
    modkit_wait(10);
    modkit_wait_for_confirm();
    modkit_text_close(0);
}
```

### modkit_caption

Shows text in window 0 and leaves it there, for as long as the scene needs it: it stays up after the event ends, while the player plays, until modkit_text_close(0).

```c
void modkit_caption(string text)
{
    modkit_text_open(0);
    modkit_text_show(0, text);
}
```

## modkit/tick.c

modkit tick: lets a map run code on a timer while the player plays, for monster scripts. Include with #include "modkit/tick.c" in a patch of the AI of a monster the map places, and call modkit_tick from a #pragma every_frame function, which runs before each of the monster's waits.

Event scripts cannot run beside play (the player waits while an event runs), but monster scripts do, and a monster can ask the map for a program with run_event_script. A map program that never waits runs within one frame without stopping play, so it can update a caption, spawn something or keep score. See docs/coding/tutorials/captions.md.

### modkit_tick

While save flag flag is set, asks the map for program every frames frames (125 is five seconds at the PAL game's 25 frames a second). The dungeon frame timer is shared by every monster on the floor, so with several monsters ticking only the first to see it run out asks. The map's program should not wait.

```c
void modkit_tick(int flag, int frames, int program)
{
    int on;
    int timer;

    on = get_dungeon_flag(flag);
    if (on) {
        timer = get_floor_timer();
        if (timer >= frames) {
            reset_floor_timer();
            run_event_script(program);
        }
    }
}
```
