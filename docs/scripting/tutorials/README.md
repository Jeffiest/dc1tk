# Scripting tutorials

These step-by-step guides show how to perform common scripting tasks in a mod. Each tutorial builds on the concepts in the [Scripting Guide](../README.md).

- [Change what an NPC says](npc-line.md): Locate an NPC dialogue handler and update its text across all five language files.
- [Change enemy behavior](enemy-behaviour.md): Modify a monster's combat AI and fork shared toolkit libraries safely.
- [Add a new enemy to a fight](new-enemy.md): Spawn different monsters in a scripted battle and configure the battle completion trigger.
- [Add a cutscene to a town](cutscene.md): Create a self-contained cutscene library and hook it into a town map with `mod.json`.
- [Tune the player](tune-player.md): Adjust Max's melee combo timing windows, attack damage, and charge attack thresholds.
- [Show live captions during a fight](captions.md): Use a monster frame timer and a non-blocking map event to display timed captions during combat.
